# 🧪 EBM Automation Project — Автоматизация eBay с Behave и Selenium

Этот проект реализует автоматическое тестирование сайта eBay с использованием Python, Selenium и фреймворка Behave (BDD). Он создан для практики и профессиональной автоматизации через чёткую структуру.

---

## 📁 Структура проекта

pharm-python-project/
├── requirements.txt            # Список всех зависимостей
├── README.md                   # Описание проекта
└── features/                   # Папка со всеми тестами
    ├── environment.py          # Настройка запуска и завершения браузера
    ├── steps/                  # Шаги Given / When / Then
    │   └── steps.py
    └── regression.feature             # Gherkin-сценарии (feature-файлы)
